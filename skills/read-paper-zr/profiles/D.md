# D 复现阅读

以本题公开method、protocol和sample为实现约束，以指定论文补充机制解释。重建输入→中间量/数据结构→运算→输出的完整链。逐个核对变量定义、索引/形状、归一化轴、求和与平均顺序、阶段可见信息，区分训练/建库与运行。核对数据划分、随机种子、排序方向、并列处理、指标单位与聚合。按实际公开样例推演中间量和结果；不能补造实验值、标签或算法。

D类当前采用以下阶段约定，优先于通用适配中“不增加独立模型阅读轮次”的默认说明：

1. 阅读阶段：根据实际给出的论文、method、protocol和sample生成内部Markdown实现依据，返回当前请求指定的markdown和evidence JSON。包含论文与任务、核心机制、复现步骤、样例与检查，引用真实原文与PDF页码。没有PDF时明确只读到了公开方法和协议，不宣称论文全文阅读。程序保存并回读这份Markdown。
2. 生成或修复阶段：以保存后回读的同一份Markdown为论文理解依据，对照公开method、protocol和sample实现run_experiment(request)。只输出完整代码；修复时保留正确部分。
3. 审查阶段：核对当前源码与同一份Markdown及公开协议，区分pass、fail和unverified。审查格式错误、缺项和未推演不能视为通过；代码修复后重新审查。

内部Markdown只作为本题复现依据，不写Obsidian，不生成局限与启发。最终D类答卷仍遵守原有正式实验输出协议。
